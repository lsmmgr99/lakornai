2. สี — สัญญาณ

นิยามใหม่ของ rev.2 — rev.1 ใช้ "ทอง = ของที่ต้องจ่าย · มรกต = ของที่ได้ฟรี" ซึ่งหมดความหมายทันทีที่ทุกตอนดูฟรี (คำสั่ง UX §1.0) แกนใหม่จึงเลิกพูดเรื่องเงิน แล้วไปจับทิศของเวลาแทน:
แกน 1 · ทอง = "ก้าวต่อไป" — แบรนด์ ปุ่มหลัก โฟกัส ตอนที่กำลังดู ตอนถัดไป สิ่งที่ชวนให้กดต่อ
แกน 2 · มรกต = "สิ่งที่คุณทำแล้ว" — ตอนที่ดูแล้ว แถบความคืบหน้า ข้อความสำเร็จ จุดยืน "ดูฟรีทุกตอน"
อ่านเป็นคู่ได้ทั้งหน้าโดยไม่ต้องอ่านตัวอักษร: ทองคือ "ไปไหนต่อ" · มรกตคือ "มาถึงไหนแล้ว" — และเพราะไม่มีของที่ต้องจ่ายอีกแล้ว สีเทา --lock ของ rev.1 จึงถูกถอดออกจากชุด token
