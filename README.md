# AiLakorn — เว็บไซต์ (v2)

ละครสั้น AI ภาษาไทย 12 เรื่อง 418 ตอน · **ดูฟรีทุกตอน ไม่ต้องสมัครสมาชิก**

เว็บชุดนี้ถูก **สร้างจาก generator** ไม่ได้เขียน HTML ทีละไฟล์
แหล่งความจริงคือ `build/` + `content.json` · ไฟล์ `.html` ที่ราก **เป็นผลผลิต อย่าแก้ตรง ๆ**

---

## หลังบ้าน (แผงจัดการเนื้อหา)

```bash
node admin/broker.mjs         # เปิด http://127.0.0.1:4190/admin/ — ล็อกอิน GitHub · บันทึกร่าง · เผยแพร่ขึ้นเว็บ
```

แก้เรื่อง/ตอน/ปกในแผง → **เผยแพร่** → CI ตรวจ V1–V13 → build → ส่งขึ้น GitHub Pages เอง (ราว 2–4 นาที)
ไม่มีฐานข้อมูล: แหล่งความจริงคือ `content.json` ใน git (ADR-001 §4/§14) · วิธีตั้งค่า GitHub App ครั้งแรกอยู่ที่ `admin/README.md`

## สิ่งที่ต้องรู้ก่อนแก้

**โดเมน** อยู่ที่เดียว: `SITE_ORIGIN` ใน `build/seo.mjs`
เปลี่ยนโดเมน = แก้บรรทัดเดียว แล้ว build ใหม่ → canonical / `og:url` / sitemap / JSON-LD `@id` ตามทั้งเว็บ

**การเปิดให้ Google เก็บดัชนี** ตอนนี้ปิดทั้งเว็บ (ค่าตั้งต้นของ `SITE_PUBLISHED` · เปิดด้วย repository variable `SITE_PUBLISHED=1` — ADR-001 §14)
เพราะยังไม่เผยแพร่และโดเมนยังไม่ยืนยัน · วันขึ้นจริงให้ตั้งเป็น `true` แล้ว build ใหม่

**หน้าตอน** สร้างครบ 418 URL แต่เปิดดัชนีแค่ `ep-1` ของแต่ละเรื่อง (12 หน้า)
ตอนที่ 2 ขึ้นไปเป็น `noindex,follow` เพราะชื่อตอนทั้งเว็บมีแค่ 32 ชื่อที่ไม่ซ้ำกันจาก 418 ตอน
ปลดเป็น `index` ได้ทันทีที่มีชื่อตอนจริง — แก้ที่ `build/pages-watch.mjs` บรรทัดที่เขียน `robots:`

**ข้อมูล** วันนี้มาจาก `content.json` ที่ราก (ADR-001 §6) · ถ้าไม่มีไฟล์นั้น `build/content.mjs`
ถอยไปอ่าน `assets/data.js` ซึ่งเป็นชุดของชั้นออกแบบ โดยตัด `views`/`following`/`subs` ออกให้

**ยอดวิว** `meta.viewsSource = "none"` ⇒ ไม่มีป้ายยอดวิวในหน้าใดเลย และหน้า `/popular`
บอกเกณฑ์ที่ใช้จริง (จำนวนตอน) ไม่อ้างว่าวัดผู้ชมมา — บังคับด้วยกฎ V12/V13 ใน `build/build.mjs`
วันที่มีระบบวัดจริง ให้ตั้ง `meta.viewsSource` พร้อม `views` ครบทุกเรื่องใน commit เดียวกัน (V10)

## "ดูต่อ" ทำงานยังไง

ทุกอย่างอยู่ในเครื่องผู้ใช้ ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์

| คีย์ใน `localStorage` | รูป | ใช้ทำอะไร |
|---|---|---|
| `lakorn.cont` | `{ slug: {ep, sec, dur, ts} }` | ตอนและตำแหน่งในตอนที่ค้างไว้ |
| `lakorn.done` | `{ slug: ts }` | เรื่องที่ดูจบแล้ว (ออกจากรายการค้าง) |
| `lakorn.follows` | `[ slug ]` | เรื่องที่ติดตาม |
| `lakorn.history` | `[ {slug, ep, ts} ]` | ประวัติการดู ใหม่สุดก่อน สูงสุด 60 |
| `lakorn.prefs` / `lakorn.set` | — | แนวที่ชอบ / การตั้งค่าการเล่น |

- เขียนกลับเมื่อ **เปิดตอน · เล่นไปทุก ~5 วินาทีของเนื้อหา · กดหยุด · สลับแท็บ · ออกจากหน้า**
- หน้าแรกและหน้าคลัง render รายการจากค่าพวกนี้ **เรียงล่าสุดอยู่บนสุด**
- ลิงก์ "ดูต่อ" พาไป `/watch/<slug>/ep-<n>/?t=<วินาที>` → กลับไปต่อจุดเดิม ไม่ใช่ต้นตอน
- ดูจบตอน → จุดค้างเลื่อนไปต้นตอนถัดไปเอง · ดูจบเรื่อง → ออกจาก "ดูต่อ" ไปอยู่ "ดูจบแล้ว"
- ไม่มีอะไรค้าง → หน้าว่างที่ออกแบบไว้ ไม่ใช่แถบเปล่า

เปิดคอนโซลแล้วเรียก `LakornProgress.list()` เพื่อดูรายการค้างดิบ ๆ ได้

> **หมายเหตุ:** รีโปยังไม่มีไฟล์วิดีโอ เพลเยอร์จึงเดินเวลาแบบจำลอง (6 เท่า) และบอกไว้ใต้เพลเยอร์
> แต่การบันทึก/อ่านความคืบหน้าทั้งหมดเป็นของจริง วันที่มี `<video>` จริงให้เปลี่ยนแค่ตัวเดินเวลา

  ถ้อยคำของป้าย facet 4 ตัวยังรอลูกค้ารับหรือแก้ (AIO-33) — แก้ที่ `build/content.mjs:203-217` ที่เดียว
