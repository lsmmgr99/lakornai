ช่องเสียบนี้ Dev ทำไว้ตั้งแต่ AIO-22 AC-7 (`build/seo.mjs:20-51`) และ **Visual-Designer
วางไฟล์ครบแล้ว 23 ต.ค. 2026** — `default.jpg` + `series-<slug>.jpg` ครบ 12 เรื่อง
ตั้งแต่นี้ `og:image` / `twitter:image` ทุกหน้าชี้ไฟล์ 1200×630 ในโฟลเดอร์นี้
ไม่ถอยไปใช้ปก 2:3 (ซึ่งถูก Facebook/X/LINE ครอปหัวท้าย) และ `build/build.mjs:345`
ไม่เตือนอีก

## สร้างไฟล์ชุดนี้ใหม่

```bash
node design/v2/share-cards.mjs          # HTML + JPEG ครบ 13 ใบ
node design/v2/share-cards.mjs ceo      # เฉพาะไฟล์ที่ชื่อมีคำนั้น
node build/build.mjs                    # แล้ว build ใหม่
```

ต้นฉบับเป็น HTML/CSS เปิดดูและแก้ได้: `design/v2/share-cards.mjs` (ตัวสร้าง)
→ `design/v2/share-src/*.html` (ต้นฉบับที่เรนเดอร์) — **ไม่ใช่ภาพที่ทำมือ**
ข้อความและตัวเลขทุกตัวอ่านจาก `assets/data.js` ตอนรัน ถ้อยคำทางการอ่านจาก
`FREE_LINE` ที่ `build/seo.mjs:17` โดยตรง สีทั้งหมดมาจาก `design/v2/tokens.css`

## ชื่อไฟล์ที่ระบบมองหา

| ชื่อไฟล์ | ใช้กับ | สถานะ |
|---|---|---|
| `default.jpg` | หน้าแม่ทุกหน้า (`/`, `/search/`, `/popular/`, …) | ✅ ส่งแล้ว |
| `series-<slug>.jpg` | หน้าเรื่องนั้น เช่น `series-durian-revenge.jpg` | ✅ ส่งแล้ว 12/12 |
| `ep-<slug>-<n>.jpg` | หน้าตอนนั้น | ยังไม่ทำ — ชื่อตอนจริงยังไม่มี |

ลำดับการเลือก: `ep-…` → `series-…` → `default` → ถ้าไม่มีเลยถอยไปใช้ปก 2:3
หน้าตอนจึงได้ `series-<slug>.jpg` อัตโนมัติ (`build/seo.mjs:48`) และไม่ขึ้นคำเตือน

## กติกาของภาพในโฟลเดอร์นี้ (AIO-32 เกณฑ์ตรวจรับ)

- 1200×630 ทุกใบ · JPEG · **ไม่เกิน 300 KB** (crawler ของ LINE ตัดไฟล์ที่หนักเกินทิ้ง)
  ตัวเรนเดอร์ไล่คุณภาพลงอัตโนมัติจนไม่เกินลิมิต และหยุดทำงานถ้าลงสุดแล้วยังเกิน
- **ห้ามมียอดวิว ห้ามมีดาว/คะแนน ห้ามมีคำว่า mockup** — ยอดวิวถูกถอดออกจากเว็บแล้ว
  (`meta.viewsSource = "none"`) เอากลับมาในภาพแชร์ไม่ได้ · มีด่านตรวจข้อความใน
  `design/v2/share-cards.mjs` ที่โยน error ถ้าคำต้องห้ามหลุดเข้ามาใน HTML
- ลุค "ม่านทอง" ใช้ token เดิม (`--accent:#F5C451`) ห้ามตั้งสีใหม่ในไฟล์นี้
