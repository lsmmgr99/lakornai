# ช่องเสียบภาพแชร์ 1200×630 (og:image) — AIO-22 AC-7

UX §2.4 กฎ 5 และ §6.16 สั่งให้มีเทมเพลตภาพแชร์ 1200×630 แต่ SEO (AIO-19 B-02) ตรวจแล้วว่า
`visual-design` ยังไม่ได้ออกแบบให้ — **งานนี้ยังไม่มีคนทำ** หน้าบ้านจึงทำช่องไว้ให้เสียบแทน

## วิธีใช้
วางไฟล์ `.jpg` / `.png` / `.webp` ขนาด **1200×630** ลงในโฟลเดอร์นี้ตามชื่อข้างล่าง
แล้วรัน `node build/build.mjs` ใหม่ — **ไม่ต้องแก้โค้ดแม้แต่บรรทัดเดียว**

| ชื่อไฟล์ | ใช้กับ |
|---|---|
| `default.jpg` | หน้าแม่ทุกหน้า (`/`, `/search/`, `/popular/`, …) |
| `series-<slug>.jpg` | หน้าเรื่องนั้น เช่น `series-durian-revenge.jpg` |
| `ep-<slug>-<n>.jpg` | หน้าตอนนั้น เช่น `ep-durian-revenge-1.jpg` (ถ้าทำรายตอน) |

ลำดับการเลือก: `ep-…` → `series-…` → `default` → **ถ้าไม่มีเลย ถอยไปใช้ปก 2:3 ของเรื่อง**
(ปก 2:3 ถูกครอปเสียหายบน Facebook/X/LINE ที่ใช้ ~1.91:1 จึงเป็นทางถอย ไม่ใช่ทางที่ถูก)

`build/build.mjs` จะเตือนตอน build ทุกครั้งที่ยังไม่มีไฟล์ในนี้
ตำแหน่งโค้ด: `build/seo.mjs` ฟังก์ชัน `shareImage()`
